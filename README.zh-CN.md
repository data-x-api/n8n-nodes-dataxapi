# n8n-nodes-dataxapi（中文说明）

给 [n8n](https://n8n.io) 用的 [DataXAPI](https://dataxapi.com/zh/?ref=n8n) 社区节点：在工作流和 AI Agent 里取抖音、小红书、微信公众号、视频号、微博、B站、知乎、快手的公开数据，也能取巨量算数（抖音指数）、蒲公英、星图，以及 TikTok、YouTube、X、Reddit。34 个现成操作，另外用“任意接口”能用到全部 237 个接口。

- **不用登录你自己的平台账号**，不用 Cookie、不用扫码。
- **按次付费，出错不收费。**每个操作写明了价格，`One Item per Page` 输出里的 `billing.amount` 写明这次扣了多少（美元）。
- **免费试用，最多 333 次，不用绑卡。**最低充 $10，余额不过期；支持支付宝、微信支付和银行卡。

源码：<https://github.com/data-x-api/n8n-nodes-dataxapi> · 联系：support@dataxapi.com

## 安装

在 n8n 的 **Settings → Community Nodes → Install** 输入包名 `n8n-nodes-dataxapi`。见 [n8n 社区节点安装说明](https://docs.n8n.io/integrations/community-nodes/installation/)。

## 凭证

1. 在 <https://dataxapi.com/console/keys/?ref=n8n> 创建 Key。
2. 在 n8n 里新建 **DataXAPI API** 凭证，粘贴 Key（以 `dx_` 开头）。
3. n8n 用免费的 `GET https://api.dataxapi.com/v1/account` 测试凭证，不扣钱。

价格以 [dataxapi.com/zh/apis](https://dataxapi.com/zh/apis/?ref=n8n) 上的接口页为准。

通用设置：

- **Max Pages**（默认 1）：顺着 `page.next_cursor` 往后取，最多取这么多页。每一页是一次收费调用。
- **Output**：*One Item per Result*（每条作品、评论或账号是一个 n8n item，可以直接接 Google Sheets、飞书、Slack），或 *One Item per Page*（每次调用一个 item，带 `endpoint`、`params`、`data`、`page`、`billing`、`warnings`）。
- **Options → Start Cursor**：从之前存下的 `page.next_cursor` 接着取。

出错时节点停下，写明 DataXAPI 的错误码、扣没扣钱；打开 **Continue On Fail** 时错误变成输出里的一条。

## 拿来做什么

- **竞品公众号新文章进表格**：Schedule Trigger 每天 9 点 → 微信公众号 *Articles* 取最新一页 → Code 节点去掉见过的 → Google Sheets 追加。每个号每天 $0.02。
- **小红书品牌口碑日报**：*Note Search* 搜品牌名、排序 latest → 对点赞最多的几篇 *Note Comments* → AI 节点归类好评、差评、问题 → 发到飞书或 Slack。
- **选题前看热度**：抖音 *Trend-index Keyword Trends* 一次查 1 到 5 个词的逐日搜索指数 → *Trend-index Related Keywords* → AI 节点判断哪个词在涨。
- **给 AI Agent 当工具**：节点可以直接挂到 AI Agent 上，字段用 `{{ $fromAI('query', '要搜的关键词') }}` 让模型来填。要用全部接口，给 Agent 加 *Any Endpoint → Find*（免费）和 *Call*，或者在 MCP Client Tool 里填 `https://api.dataxapi.com/mcp`。

可导入的工作流模板在 [templates/](templates/README.md)。

## 本地开发和测试

需要 Node.js 22 或更新。

```bash
npm install
npm run build   # 编译到 dist/
npm test        # 先编译，再跑 node:test；所有 HTTP 请求都是 mock 的
npm run lint    # n8n 社区节点的检查规则
```

操作由 `scripts/generate-operations.mjs` 从 DataXAPI 的实时目录生成；目录或价格变了，重新运行它。
